## Pass1word

### Pass1word — один секрет в файле, отдельный пароль для каждого сайта

**Pass1word** — персональный генератор паролей, который после первоначальной настройки требует ввести только адрес сайта.

Перед использованием пользователь один раз записывает свою мастер-фразу в константу `MASTER_PHRASE` внутри HTML-файла. После этого программа вычисляет пароли по схеме:

```text
мастер-фраза + адрес сайта → пароль
```

Одна и та же мастер-фраза создаёт разные пароли для разных сайтов. Для восстановления пароля достаточно открыть свою копию программы и снова ввести адрес в том же формате.

### Основная особенность

Пользователю не нужно каждый раз вводить секрет. Он уже содержится в персональном файле, а потому работа с программой сводится к одному действию: указать сайт.

Это удобно, но меняет модель хранения секрета: **файл с мастер-фразой необходимо беречь так же, как базу паролей**. Его нельзя публиковать, отправлять другим людям или выкладывать в открытый репозиторий.

При переносе на другое устройство нужно скопировать именно свою настроенную версию файла.

### Кому подходит

Pass1word подходит тем, кто хочет:

- получать отдельные пароли для разных сайтов;
- вводить при каждом использовании только адрес;
- хранить один персональный HTML-файл вместо базы паролей.

Адрес сайта следует записывать последовательно: например, всегда использовать `example.com`, если программа была настроена именно на такой вариант. Другие формы записи могут создать другой пароль.
