## Pass2words

### Pass2words — мастер-фраза и сайт

**Pass2words** — программа для создания отдельных паролей на основе одной запоминаемой мастер-фразы и названия сервиса.

Наиболее естественный способ использования:

```text
Первое поле  = личная мастер-фраза
Второе поле  = адрес или название сайта
```

Программа объединяет оба значения, вычисляет SHA-256 и создаёт пароль:

```text
мастер-фраза + сайт → уникальный пароль для этого сайта
```

При следующем посещении пользователь повторяет тот же ввод и восстанавливает тот же пароль. Меняется только название сервиса — мастер-фраза может оставаться неизменной.

### Основная особенность

В исходном коде нет секрета. Программу можно открыто публиковать, копировать и запускать на любом устройстве.

Секретом является только мастер-фраза, которая остаётся в памяти пользователя. Её не нужно записывать в файл или сохранять в базе паролей.

Порядок полей важен: мастер-фраза должна всегда находиться в первом поле, а сайт — во втором.

### Кому подходит

Pass2words подходит тем, кто хочет:

- помнить одну личную фразу;
- получать разные пароли для разных сервисов;
- не хранить пароли и не синхронизировать базу между устройствами;
- использовать программу с открытым исходным кодом.

Это наиболее прямолинейная схема проекта: **одна фраза в памяти, а название сайта выбирает конкретный пароль**.
