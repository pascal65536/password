Pass2words — генератор, где пользователь вводит два слова. Они нормализуются (trim + lowerCase), объединяются через |, хешируются SHA-256, и из хеша собирается пароль на 16 символов с гарантией всех категорий.

Особенность: нет мастер-фразы в коде — секрет полностью на стороне пользователя. Два поля, порядок важен. Есть индикация планируемой и фактической длины.
