Pass3words — развитие идеи до трёх слов, как в what3words. Три поля с чекбоксами блокировки: можно исключить любое слово, и пароль посчитается без него. Порядок слов имеет значение.

Особенность: наиболее близко к концепции «адрес из трёх слов». Чекбоксы позволяют гибко управлять тем, какие слова участвуют в генерации. Планируемая длина — PASSWORD_LENGTH (16).
