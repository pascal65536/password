## Pass3words

### Pass3words — пароль из личной мнемоники

**Pass3words** — программа для восстановления пароля по одному, двум или трём личным фактам, событиям или утверждениям.

Пользователь запоминает не случайный набор символов, а понятную ему комбинацию фраз. Это могут быть реальные воспоминания, выдуманные события, необычные сочетания слов, даты или целые предложения. Факты не обязаны быть настоящими — важно, чтобы пользователь мог стабильно воспроизвести их по памяти.

```text
личный факт + личный факт + личный факт → пароль
```

Получается своя «память на кончиках пальцев»: при следующем использовании человек просто повторяет привычный ввод.

### Три поля вместо одной фразы

Разделение мнемоники на поля позволяет связать несколько независимых воспоминаний. Порядок активных фрагментов влияет на результат.

С помощью переключателей можно исключить любое поле из вычисления. Пустые и отключённые поля не участвуют в создании пароля. Поэтому программу можно использовать с одной, двумя или тремя фразами.

Для получения разных паролей на разных сайтах одно из полей удобно отвести под название или адрес сервиса. Например:

```text
Поле 1 = сайт
Поле 2 = личное воспоминание
Поле 3 = выдуманное событие
```

Если использовать одинаковую мнемонику без указания сайта или другого назначения, каждый раз будет получаться одинаковый пароль.

### Основная особенность

Pass3words не требует хранить ни мнемонику, ни пароли. Код можно не скрывать: секретом являются исходные фразы и порядок их ввода.

Регистр и пробелы по краям не важны. Внутренние пробелы, знаки препинания, числа и формулировки необходимо воспроизводить одинаково.

### Кому подходит

Pass3words подходит тем, кому проще запомнить несколько личных ассоциаций, чем одну длинную мастер-фразу или случайный пароль.

Это наиболее мнемонический вариант проекта: **пароль не хранится, а восстанавливается из личной истории, которую помнит пользователь**.
