# Passwords Project

Набор минималистичных генераторов паролей в одном HTML-файле. Каждый генератор работает офлайн, без зависимостей и без отправки данных на сервер.

## Идея

Проект исследует разные подходы к **мнемоническим паролям** — когда пользователь запоминает не случайный набор символов, а осмысленную фразу, из которой детерминированно вычисляется пароль.

Вдохновение — система адресации **what3words**, которую Монголия внедрила для почтовой доставки: каждый квадрат 3×3 метра на Земле получает уникальный адрес из трёх слов. Запомнить три слова проще, чем координаты.

## Генераторы

| Папка | Название | Подход |
|---|---|---|
| `pass1word/` | Pass1word | Одно слово (адрес сайта) + мастер-фраза → пароль |
| `pass2words/` | Pass2words | Два слова → хеш → пароль |
| `pass3words/` | Pass3words | Три слова (как адрес what3words) → хеш → пароль |

## Общие принципы

- **Детерминизм:** одинаковый ввод → одинаковый пароль
- **Нормализация:** регистр и крайние пробелы не влияют на результат
- **Порядок слов важен** (для 2 и 3 слов): `кот пёс` ≠ `пёс кот`
- **Нет сервера:** всё считается в браузере через `crypto.subtle`
- **Один файл:** каждый генератор — автономный `index.html`

## Запуск

Открыть `index.html` в любой папке в браузере. Всё.
